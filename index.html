1. Instellingen & Context

Hoe maak je een gratis API-sleutel aan?
1. Klik op deze link naar Google AI Studio.
2. Log in met een Google-account. (Blokkeert je VIVES-mail de toegang? Gebruik dan een persoonlijk @gmail.com account!)
3. Klik op de blauwe knop 'Create API key'.
4. Kopieer de sleutel en plak deze hierboven. Je sleutel wordt uitsluitend lokaal in jouw browser bewaard.

2. Jouw Dossier (Enkel PDF bestanden)

Sla je PowerPoint/Keynote eerst op als PDF via 'Opslaan als' > PDF.

De AI-coach analyseert je bestanden, bestudeert de rode draad en trianguleert de didactiek...
