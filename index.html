VIVES Didactische Coach Geschiedenis

Upload je lesvoorbereiding, presentatie en werkblad (als PDF) voor formatieve feedback.

1. Instellingen

Hoe maak je een gratis API-sleutel aan?
1. Klik op deze link naar Google AI Studio.
2. Log in met een Google-account. (Let op: Blokkeert je VIVES-mail de toegang? Gebruik dan gewoon een persoonlijk @gmail.com account!)
3. Klik op de blauwe knop 'Create API key' (en eventueel op 'Create API key in new project').
4. Kopieer de lange reeks letters en cijfers en plak deze hierboven. Je sleutel wordt uitsluitend lokaal in jouw browser bewaard.

2. Jouw Dossier (Enkel PDF bestanden)

Sla je PowerPoint/Keynote eerst op als PDF via 'Opslaan als' > PDF.

De AI-coach analyseert je bestanden, bestudeert de rode draad en trianguleert de didactiek...
Dit zware denkproces duurt gemiddeld 30 tot 60 seconden. Even geduld!
